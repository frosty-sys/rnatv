Store image asset source mapping
===============================

The repository already contains image sources referenced by the project README. To complete the Fastlane image set, copy/rename the binary assets to the Fastlane paths below:

• icon.png — app/metadata/android/en-US/images/cropped_circle_image.png
• tvBanner.png — app/src/main/res/drawable/ic_tv_banner2.png
• phoneScreenshots/1.png — assets/screenshots/search.png
• phoneScreenshots/2.png — assets/screenshots/file.png
• phoneScreenshots/3.png — assets/screenshots/setup.png

These are source-path references only; Fastlane expects actual image files at the destination paths. The original source images are left in place.
